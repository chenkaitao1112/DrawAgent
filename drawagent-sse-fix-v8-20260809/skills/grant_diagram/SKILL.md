# 基金绘图

我希望这个 skill 帮我把一份基金申请材料变成一张清楚、有说服力的图。它面对的不是论文读者，而是基金评审专家，所以图里最重要的不是把某个算法细节画得很复杂，而是让人一眼看懂这个项目为什么值得做、打算解决什么问题、有什么创新、准备怎么一步步完成。

使用这个 skill 时，最好先读完整的申请书、项目申报书、研究计划或技术路线材料。如果没有完整文档，也可以根据我粘贴的项目背景、研究内容、创新点、技术路线、年度计划、预期成果来做。材料不够时，应该先问我要原文或更具体的内容，不要凭空编一个项目。

请先帮我理解项目的背景和问题意识。也就是说，要从材料里看出这个项目面对什么现实需求或科学问题，已有工作哪里不够，项目最终想达成什么目标。

接着请整理项目的创新点和研究内容。这里不要把申请书里的套话照搬出来，而是要提炼成图里能放得下的几个关键模块，让评审专家能看出这个项目的新意在哪里。

然后请梳理技术路线。重点看不同研究任务之间是什么关系，哪些任务先做，哪些任务互相支撑，哪些结果会进入后续验证或应用示范。技术路线要像一条能走通的路，而不是一堆并列名词。

在图的表达上，我希望它更像基金申请书里的“研究内容与技术路线图”：上面可以呈现研究目标或关键问题，中间呈现若干研究任务、方法模块和创新点，下面呈现验证、应用或预期成果。整体要层次清楚、逻辑顺畅、文字不要太密。

最后请把前面整理出的内容汇总成一段英文绘图 Prompt。这个 Prompt 应该能直接交给绘图模型使用，画出一张干净、正式、适合项目申请材料的技术路线图。风格上要学术、克制、清晰，不要海报感、不要炫酷装饰、不要把图做成商业宣传页。
